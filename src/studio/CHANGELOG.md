# 变更日志

本项目的所有重要变更都会记录在此文件中。

格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，
版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [Unreleased]

### 新增

- 架构编辑器：部门与岗位的新增、改名、调整上级、删除（删部门为归档），写操作直接生效并落字段级 ChangeRecord（审批态 `auto`，版本历史可查）
- 删除护栏：有子部门或岗位的部门不可删；仍挂在成员名下的岗位不可删，提示先行
- 编辑入口：AppBar「新增部门 / 新增岗位」，选中部门或岗位后出现「部门操作 / 岗位操作」菜单
- 提示条改为替换式（连续操作不排队堆叠）；架构树不再展示已归档部门
- 测试 `org_structure_editor_test.dart` 六例：增、改、删、两道护栏、变更留痕

## [0.1.0-alpha.2] - 2026-08-14

### 修复

- 发布管线：落地 OSS 发布桶 IaC（terraform apply → `qtcloud-org-studio`，静态网站托管 + 公共读）
- 发布管线：接入 CDN 域名 `org.cloud.quanttide.com`（源站 OSS，对齐 `delib.cloud.quanttide.com` 配置）

## [0.1.0-alpha.1] - 2026-08-14

### 新增

- 量潮组织云工作台原型：首页 / 架构 / 成员 / 组织健康度四个页面
- 组织架构浏览：部门 → 岗位 → 汇报链路，编制管控与超编/空缺警示
- 变更即提交：发起变更落 `ChangeRecord`（待审批），版本历史可追溯
- 成员兼任表达与单点风险标注；成员变动影响（岗位空缺 / 职责悬空）
- 组织健康度：OHI 九维度从组织数据推导 + 组织温度计（复盘为机制健康数据源）
- 复盘记录：日程 / 组织者 / 参与人 / 结论沉淀，状态流转与组织者变更提醒
- 全平台客户端骨架（Web / 桌面 / 移动），Web 版发布管线（OSS + CDN）
